# Nerd Subscription Tracker — downloads

**Every subscription. One clear view.**

This repository holds only the Windows installers and the update files the app
checks automatically. It contains no source code and no user data.

## Install

1. Open the [latest release](https://github.com/javeshkhan0/nerd-subscription-tracker-releases/releases/latest)
   and download `Nerd-Subscription-Tracker-Setup-<version>.exe`.
2. Run it. Windows may show "Windows protected your PC" because the installer is
   not code-signed: click **More info → Run anyway**.
3. Open NERD and add your subscriptions. Your data stays on your PC; nobody else
   can see it.

## Updates

NERD checks for updates on its own, downloads them in the background and asks you to
restart when one is ready (Settings → General → App updates shows the status).
Updating keeps your data, keys and settings.

## Optional phone alerts

Settings → Integrations → Pushover phone alerts. Each person uses their own
Pushover account; nothing is shared between installations.
